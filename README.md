## ◈ About the Project

**AURAX** is an experimental generative art project exploring the intersection of programming, mathematics and visual creativity.

Built entirely with Python and its native Turtle Graphics library, the project transforms algorithms, geometric structures and mathematical expressions into unique digital compositions.

Every artwork is created through code — from intricate geometric mandalas to mythical creatures.

No pre-rendered illustrations. No external graphics engines. Just Python, mathematics and imagination.

## ◈ Getting Started

### Requirements

- Python 3.10 or newer.
- Tkinter support.
- Windows, Linux or macOS.

### Installation

Clone the repository:

```bash
git clone https://github.com/OtavioTavaresDev/aurax-generative-art.git
```

Navigate to the project:

```bash
cd aurax-generative-art
```

### Run an artwork

**Cosmic Mandala**

```bash
python cosmic_mandala.py
```

**Crimson Dragon**

```bash
python aurax_dragon.py
```

No `pip install` required.
